🎓 Udemy Clone (HTML & CSS)

A responsive front-end clone of the popular online learning platform Udemy, built using only HTML5 and CSS3. This project focuses on recreating the layout and design of Udemy’s homepage to practice modern web design techniques and responsive layouts.

🚀 Features

📌 Responsive navigation bar

🎨 Clean and modern UI design

📚 Course listing section with cards

⭐ Ratings and pricing display

📱 Responsive layout for different screen sizes

🖱️ Hover effects and smooth styling

🛠️ Built With

HTML5

CSS3 (Flexbox & Grid)

🎯 Purpose of the Project

This project was created to:

Practice structuring web pages using semantic HTML

Improve CSS styling and layout skills

Understand responsive web design concepts

Replicate a real-world website UI
